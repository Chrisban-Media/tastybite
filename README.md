# TastyBite

TastyBite is a simple, responsive restaurant landing page built with plain HTML CSS and Javascript.

## Features

- Hero section with call-to-action buttons
- Popular dishes menu with prices and order links
- About section for restaurant information
- Contact section with a click-to-call order button
- Responsive layout with food imagery from Unsplash
- Smooth scrolling navigation

## Project Structure

```text
.
├── index.html
├── style.css
├── script.js
└── README.md
```

## Getting Started

No build tools or dependencies are required.

1. Open `index.html` directly in a browser.
2. Alternatively, serve the folder with any local static server.

## Customization

- Edit the content, prices, links, and phone number in `index.html`.
- Update colors, layout, typography, and responsive styles in `style.css`.
- Replace the Unsplash image URLs with your own restaurant imagery as needed.
